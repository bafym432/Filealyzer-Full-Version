## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Thorough File Analysis** — Get in-depth information about file properties including version, size, and attributes.
- **CRC-32 and MD5 Checks** — Ensure file integrity with detailed checksum information.
- **Hex Dump View** — Perform searches within a hex dump for advanced analysis.
- **Resource Inspection** — View resources used by executable files, including icons and text.
- **Custom Report Generation** — Save analysis reports in text, HTML, or XML formats.

### Advanced Features:
- **Clipboard Support** — Easily copy analysis results directly to your clipboard.
- **Context Menu Integration** — Right-click any file to quickly analyze it with **Filealyzer**.
